# Enchères TikTok LIVE

Site d'enchères avec les pièces TikTok : timer, compteur, classement, anti-snipe, overlay OBS, et un bot qui lit le live et compte chaque cadeau.

```
npm install
npm start        # http://localhost:3000
```

- Onglet **Bot TikTok** : entre le pseudo du streamer (en live) → connecter.
- Onglet **Réglages** : durée, mise minimum, anti-snipe, bonus, prolongation + simulateur de cadeaux.
- **Overlay OBS** : `http://localhost:3000/overlay.html` (source Navigateur).
